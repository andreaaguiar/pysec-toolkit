# Security Policy

## Reporting a Vulnerability

Report a security issue in this toolkit through GitHub private vulnerability reporting. Open the repository **Security** tab and choose **Report a vulnerability**. This keeps the report private until a fix is ready.

Please include:

- The affected tool or file
- Steps to reproduce the issue
- The impact you observed

Do not open a public issue for a security report.

## Response

- We aim to acknowledge a report within 7 days.
- We confirm the issue and work on a fix.
- We credit you in the release notes unless you ask otherwise.

## Scope

This repository contains offensive security tools for authorized testing. A valid report describes a flaw in the toolkit code itself. Examples are a crash, an injection in the tool, or unsafe handling of input or output.

Use of these tools against systems without permission is out of scope. See the ethical and legal guidance in the [README](./README.md).

## Supported Versions

This project uses a rolling model. Fixes land on the `main` branch. Use the latest commit on `main`.
